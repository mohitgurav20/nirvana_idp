Physiological Stress Index

Your three biometric inputs feed into a real-time linear regression model running on our Flask backend. The model calculates your Physiological Stress Index (0–100 scale) every 2 seconds using a trained AI algorithm.

Real-Time Regression Model
Stress Index = β₀ + β₁(BPM) + β₂(Movement_Hz) + β₃(Lux) Current Model Coefficients: β₀ (Baseline Stress) = 12.4 β₁ (Heart Rate Weight) = +0.38 (higher BPM → higher stress) β₂ (Movement Weight) = +2.1 (more movement → higher stress) β₃ (Light Weight) = -0.08 (more light → lower stress) Model Performance: R² Score = 0.84 (84% variance explained) Mean Absolute Error = 4.2 points Training Data = 200+ labeled sessions

Open Source Hardware Integration

Nirvana is engineered entirely on open-source hardware modules, giving students and researchers full architectural control to audit and build physiological systems.

ESP32 Dev Module

Integrates dynamic 240MHz dual-core processing speed with low-power Wi-Fi pathways to transmit telemetry biometrics every 2 seconds without high energy draw.

Clinical Biometrics

Uses MAX30102 multi-wavelength photoplethysmography (PPG) arrays to measure red and infrared reflection, tracking Cardio Rhythm and HRV trends.

Multi-channel Data

Fused actigraphy via MPU6050 accelerometer and ambient light arrays using LDR sensors maps comprehensive physiological reactions directly on the Flask AI engine.
